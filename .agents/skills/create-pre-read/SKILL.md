# Curriculum pre-read workflow

Find the repository root containing `curriculum-index.json` and `preread/`.
Read `preread/SKILL.md` in full and follow its pipeline.
Resolve the exact batch/module/lecture output path before authoring.
Run the creator and reviewer sequentially using `preread/agents/creator.md` and `preread/agents/reviewer.md`.
Preserve the existing curriculum folders and save the result as `pre-read.md`.
