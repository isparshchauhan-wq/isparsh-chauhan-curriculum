## Learning objectives

- Explain, with a visual intuition, why data is split across related tables and why we join them
- Write an INNER JOIN to combine matching rows across two tables
- Write a LEFT JOIN and explain how it preserves unmatched rows from the left table
- Predict how many rows a join will return before running it
- Combine a join with WHERE and GROUP BY to answer a business question on a sales dataset
